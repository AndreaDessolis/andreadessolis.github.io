Web Navigation

An NVDA add-on that adds the JAWS web features that NVDA does not have. It works in Chrome, Edge and Firefox.

The add-on acts only on web pages. In programs that are not web pages, even when NVDA is in browse mode (for example a message open in Outlook, Word, WordPad), its keys do nothing new: NVDA behaves as without the add-on.

Each feature can be turned on and off in NVDA Settings, Web Navigation category. A feature that is off leaves its keys to NVDA, which behaves as without the add-on. The keys can be changed in Input gestures, Web Navigation category.

The single letters (à, ò, ù, J, Y) work only in browse mode and with single letter navigation on (NVDA+Shift+Space). In text fields they are typed as usual.

The à, ò and ù keys are on the Italian keyboard. On other keyboards, assign other keys to these commands in Input gestures, Web Navigation category.

Links in headings

On sites like YouTube the title of each video is a heading that contains a link. When moving with H or the numbers:

  • The full line is read: after the title, NVDA also reads what the link label adds (on YouTube, the video length).
  • The focus moves to the link, as with JAWS: Tab continues from there, for example to the channel link of that video.

Check boxes in the settings: Read the full label of the link in headings and Move the focus to the link of the heading.

Open the link where you are

In NVDA, Shift+Enter and the other keys below go to the browser, which acts on the link that has the focus, not on the one where the NVDA cursor is. So the wrong link was opened. With the add-on the focus first moves to the link where you are, even if you got there with the arrow keys:

  • Shift+Enter: new window.
  • Control+Enter: new background tab.
  • Control+Shift+Enter: new foreground tab.
  • Applications or Shift+F10: context menu of the link, for example to copy its address.

Outside a link, or outside a web page, these keys do what they would do without the add-on (for example in Thunderbird or WhatsApp). Check box: Open the link where you are.

Page address

NVDA+A reports the address of the open web page. Pressed twice, it copies it to the clipboard and says "Address copied". The focus must be inside the page: outside the page (for example in the address bar or in another program) the key does what it does in NVDA. Check box: Page address with NVDA+A.

The key works only with the desktop keyboard layout: in the laptop layout NVDA+A is NVDA's say all and stays that way. With the laptop layout you can assign another key in Input gestures.

JAWS-like quick navigation keys

The same letter as JAWS when it is free in NVDA, otherwise an accented letter of the Italian keyboard. NVDA's keys all stay as they are.

  • à and Shift+à: tabs (the apostrophe in JAWS).
  • ò and Shift+ò: articles (O in JAWS, which in NVDA is for embedded objects).
  • ù: main landmark, the real content of the page (Q in JAWS, which in NVDA is for block quotes). If there is none after the cursor, it starts again from the top of the page.

Check box: JAWS-like quick navigation keys.

Scroll and try again

Many sites (chats, social networks, pages that grow by themselves) keep only part of their content in the page and load the rest when the page scrolls to the top or the bottom. That is why quick navigation keys, NVDA's ones too like H, stop at the elements already loaded.

The add-on keys (à, ò, Y) work differently: if they find nothing more, you hear a short beep, the page scrolls past the first (or last) loaded element, the add-on waits for the site to load and tries again, up to two times. If something arrives it moves there, otherwise NVDA says there are none. If you move in the meantime, the search stops.

It does not work on sites that load more only with a button like "Show more". NVDA's keys (H, K...) stay as they are. Check box: Scroll the page to look for more elements.

A search that remembers the word for each page

NVDA's search remembers a single word for all pages and forgets it when NVDA restarts. With the add-on each page has its own: when you open the search, the word is already there and selected (Enter to search it, or type a new word). NVDA+F3 and NVDA+Shift+F3 use the word of the page. The case sensitive check box is remembered too. On a page never searched you find the last word searched elsewhere, as in NVDA.

The page is recognized by its address, without the part after the hash sign (#). Up to 500 pages are remembered: beyond that, the oldest are forgotten.

In the settings: check box Remember the search for each page and button Delete the remembered searches.

Page elements (NVDA+F6)

Like Insert+F3 in JAWS. The window has, in Tab order:

  1. Type of element (Alt+T): chosen with the arrow keys; each item shows how many there are, for example "Buttons: 12". Only the types present in the page appear. Enter moves to the list.
  2. Filter (Alt+F): typing part of the name narrows the list.
  3. Elements (Alt+E): in page order, already on the element where you are. Enter moves to the element.
  4. Buttons Move to (Alt+M), Activate (Alt+A, presses or opens the element) and Cancel (Escape).

The window opens again on the last type used. Types: headings, smart points, links, buttons, edit fields, check boxes, radio buttons, combo boxes, form fields, graphics, tables, lists, frames, landmarks, articles, tabs.

In Input gestures there are also the commands "List of buttons", "List of tables" and so on, like Control+Insert+letter in JAWS: they open the window already on that type, with the focus on the list. They have no key: assign one if you need it.

NVDA's elements list (NVDA+F7) stays as it is. Check box: Page elements with NVDA+F6.

Placemarkers

  • NVDA+J opens "Add Placemarker": the Name already contains the text of the line, selected; Valid for chooses "Only this page" or "The whole site" (every page of the site where that text is). The window remembers the last choice. If the line already has a placemarker, NVDA says so and the window does not open.
  • Control+Windows+J sets the temporary placemarker, like Control+Windows+K in JAWS: no window, only one per page (pressed again it moves to the line where you are), not saved to a file: it lasts until NVDA restarts. NVDA says "Temporary placemarker set".
  • J and Shift+J move to the next and previous placemarker and read the line; at the end they start again from the other side.
  • NVDA+Shift+J opens "Placemarkers": the list of the placemarkers of the page and of the site, with Move to (or Enter), Rename, Delete (or the Delete key), Delete all (asks for confirmation) and Close. Site placemarkers have "(site)" after the name, the temporary one "(temporary)"; those whose text is not on the page are marked "not on this page".

Pages change: for each placemarker the text of the line and its position are remembered. The text is searched, even if it moved; if it appears more than once, the one with the same lines before and after is chosen, then the one closest to the previous position. If the text is gone, a page placemarker uses the previous position.

In the settings: check box Placemarkers and button Delete all the placemarkers.

Smart points

Like the Smart Glance of JAWS. A smart point is a piece of text that stands out to the eye because it has a style that is rare in the page: a color, a background, a font, a size, bold, italic, highlighted text. Often it is not a heading, so H does not reach it: for example a phone number in evidence or a colored notice.

  • Y and Shift+Y: next and previous smart point; NVDA reads its text.
  • NVDA+Control+Y: list of smart points, in the Page elements window (where they are also among the NVDA+F6 types).
  • When the page opens NVDA says how many smart points there are, for example "4 smart points". If there are none it says nothing.

How they are chosen: the most used style is the normal text of the page; smart points are the pieces of text with a style used in a small part of the page, the rarest first. As in JAWS, links, headings and form fields are left out (of the fields, the required ones or those with errors are kept). The calculation is done when needed and done again only if the page changes.

In the settings: Smart points, Announce the smart points when the page opens, Smart points: include links, include headings, include form fields (these three off by default) and Smart points sensitivity: Normal (text with a style used in up to 5% of the page, at most 20 points) or High (up to 15%, at most 50 points).

Where the data is saved

In the NVDA settings folder (usually %APPDATA%\nvda):

  • navigazioneWeb-ricerche.json: the searched words for each page.
  • navigazioneWeb-segnaposti.json: the placemarkers.
  • The settings are in nvda.ini, navigazioneWeb section.

When the add-on is removed these files stay; they can be deleted by hand.

Languages

The add-on speaks the language of NVDA: English or Italian.

Compatibility

  • Tested with NVDA 2026.3 (64 bit).
  • Minimum version: NVDA 2024.1, including the 32 bit versions from 2024.1 to 2025.3. The add-on is written only in Python, with no compiled parts, so it does not depend on 32 or 64 bit. This was checked by comparing the NVDA code of those versions, not by trying them.
  • Valid for all NVDA 2026 versions. With NVDA 2027.1, NVDA will mark it as incompatible until a tested version is released.

Known limits

  • Tabs (à): available in NVDA from 2024.1.
  • Focus on the link of headings: on some sites, when a link gets the focus, a menu or a tooltip opens. If it bothers you, turn off the Move the focus to the link of the heading check box.
  • The add-on always takes the first link inside the heading.
  • Smart points: they depend on how the site builds the page. If it uses only one style there are none; if it uses very many there can be too many: in that case try the Normal sensitivity. On very large pages the calculation when the page opens can take a moment.
  • Some features use internal parts of NVDA. After an NVDA update it is worth trying them again.

If something does not work

  • After installing a new version, restart NVDA: the new add-on starts working only after the restart.
  • Check that the feature is on in the settings and that you are not in focus mode.
