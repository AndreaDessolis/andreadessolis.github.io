Web Navigation

An NVDA add-on that adds the JAWS web features that NVDA does not have. It works in Chrome, Edge and Firefox.

The add-on acts only on web pages. In programs that are not web pages, even when NVDA is in browse mode (for example a message open in Outlook, Word, WordPad), its keys do nothing new: NVDA behaves as without the add-on.

Each feature can be turned on and off in NVDA Settings, Web Navigation category. A feature that is off leaves its keys to NVDA, which behaves as without the add-on. The keys can be changed in Input gestures, Web Navigation category.

The single letters (à, ò, ù, J, Y) work only in browse mode and with single letter navigation on (NVDA+Shift+Space). In text fields they are typed as usual.

The à, ò and ù keys are on the Italian keyboard. On other keyboards, assign other keys to these commands in Input gestures, Web Navigation category.

Links in headings

On sites like YouTube the title of each video is a heading that contains a link. When moving with H or the numbers:

  • The full line is read: after the title, NVDA also reads what the link label adds (on YouTube, the video length).
  • The focus moves to the link, as with JAWS: Tab continues from there, for example to the channel link of that video.

Check boxes in the settings: Read the full label of the link in headings and Move the focus to the link of the heading.

Open the link where you are

In NVDA, Shift+Enter and the other keys below go to the browser, which acts on the link that has the focus, not on the one where the NVDA cursor is. So the wrong link was opened. With the add-on the focus first moves to the link where you are, even if you got there with the arrow keys:

  • Shift+Enter: new window.
  • Control+Enter: new background tab.
  • Control+Shift+Enter: new foreground tab.
  • Applications or Shift+F10: context menu of the link, for example to copy its address.

Outside a link, or outside a web page, these keys do what they would do without the add-on (for example in Thunderbird or WhatsApp). Check box: Open the link where you are.

Page address

NVDA+A reports the address of the open web page. Pressed twice, it copies it to the clipboard and says "Address copied". The focus must be inside the page: outside the page (for example in the address bar or in another program) the key does what it does in NVDA. Check box: Page address with NVDA+A.

The key works only with the desktop keyboard layout: in the laptop layout NVDA+A is NVDA's say all and stays that way. With the laptop layout you can assign another key in Input gestures.

JAWS-like quick navigation keys

The same letter as JAWS when it is free in NVDA, otherwise an accented letter of the Italian keyboard. NVDA's keys all stay as they are.

  • à and Shift+à: tabs (the apostrophe in JAWS).
  • ò and Shift+ò: articles (O in JAWS, which in NVDA is for embedded objects).
  • ù: main landmark, the real content of the page (Q in JAWS, which in NVDA is for block quotes). If there is none after the cursor, it starts again from the top of the page.

Check box: JAWS-like quick navigation keys.

Scroll and try again

Many sites (chats, social networks, pages that grow by themselves) keep only part of their content in the page and load the rest when the page scrolls to the top or the bottom. That is why quick navigation keys, NVDA's ones too like H, stop at the elements already loaded.

The add-on keys (à, ò, Y) work differently: if they find nothing more, you hear a short beep, the page scrolls past the first (or last) loaded element, the add-on waits for the site to load and tries again, up to two times. If something arrives it moves there, otherwise NVDA says there are none. If you move in the meantime, the search stops.

It does not work on sites that load more only with a button like "Show more". NVDA's keys (H, K...) stay as they are. Check box: Scroll the page to look for more elements.

Blank lines skipped

Many pages have blank lines that slow down reading with the arrow keys. In web pages, in browse mode, Up and Down arrow (lines) and Control+Up and Down arrow (paragraphs) do not stop on blank lines: they go straight to the next line that contains something, as JAWS does.

  • A line with a graphic, a field, a button, a separator or another element that NVDA announces is not blank: it is always read.
  • Every line on which NVDA would only say "blank" is skipped, including lines made of hidden elements with no text (for example at the top of GitHub pages).
  • In tables, an empty cell is a blank line and the arrows skip it. NVDA's table commands (Control+Alt+arrows) also stop on empty cells.
  • At the top and bottom of the page, if only blank lines follow, you stay where you are, as in NVDA.
  • Say all, text selection and other documents (Word, Outlook...) stay as in NVDA. If NVDA's paragraph style is "multi-line break", Control+Up and Down arrow follow that setting.

Check box: Skip blank lines when moving with the arrows (on by default). NVDA+Shift+7 turns it on and off at any time, for sites that put something useful on lines that look empty: NVDA says "Blank lines skipped" or "Blank lines read". On the Italian keyboard Shift+7 is the slash, which is not a single key there; on other keyboards you can assign NVDA+slash, or any other key, in Input gestures.

Enter in text fields

Many sites, for example ChatGPT, draw a text like "Ask anything" inside the empty field. The browser presents it as an element of its own, not as the field: in NVDA, with the cursor on it, Enter does not switch to focus mode. With the add-on, if the cursor is on such a text and the field contains it, Enter acts on the field: NVDA moves the focus to it and switches to focus mode, so you can type right away. On links, buttons and the other elements Enter does what it does in NVDA.

Check box: Enter on the text drawn inside a field switches to focus mode (on by default).

In Thunderbird messages

Messages open in Thunderbird are read in browse mode like a web page. There, skipping blank lines, Go back to where you were (NVDA+Shift+Left and Right arrow),Open the link where you are (Shift+Enter, Control+Enter, Applications), Page elements (NVDA+F6 and the List commands) and smart points (Y, Shift+Y, NVDA+Control+Y) work. The other features (placemarkers, remembered search, address, quick navigation keys) stay web-only: in Thunderbird their keys do what they do in NVDA.

A search that remembers the word for each page and site

NVDA's search remembers a single word for all pages and forgets it when NVDA restarts. With the add-on each page and each site have their own: when you open the search, the word is already there and selected (Enter to search it, or type a new word). NVDA+F3 and NVDA+Shift+F3 use the same word. The case sensitive check box is remembered too.

Every searched word is remembered both for the page and for the site (the site without "www", as for placemarkers). The Remember the searched word for list, in the settings, chooses which one to propose:

  • Page, then site (default): the word of that page; if the page has none, the last one searched on that site. Useful on sites like YouTube, where every video has a different address.
  • Page only: only the word searched on that same page.
  • Site only: the last word searched on any page of the site.

Without a remembered word you find the last one searched elsewhere, as in NVDA. The page is recognized by its address, without the part after the hash sign (#). Up to 500 pages and sites are remembered: beyond that, the oldest are forgotten.

In the settings: check box Remember the searched word, list Remember the searched word for and button Delete the remembered searches (pages and sites).

Page elements (NVDA+F6)

Like Insert+F3 in JAWS. The window has, in Tab order:

  1. Type of element (Alt+T): chosen with the arrow keys; each item shows how many there are, for example "Buttons: 12". Only the types present in the page appear. Enter moves to the list.
  2. Filter (Alt+F): typing part of the name narrows the list.
  3. Elements (Alt+E): in page order, already on the element where you are. Enter moves to the element.
  4. Buttons Move to (Alt+M), Activate (Alt+A, presses or opens the element) and Cancel (Escape).

The window opens again on the last type used. Types: headings, smart points, links, buttons, edit fields, check boxes, radio buttons, combo boxes, form fields, graphics, tables, lists, frames, landmarks, articles, tabs.

In Input gestures there are also the commands "List of buttons", "List of tables" and so on, like Control+Insert+letter in JAWS: they open the window already on that type, with the focus on the list. They have no key: assign one if you need it.

NVDA's elements list (NVDA+F7) stays as it is. Check box: Page elements with NVDA+F6.

Placemarkers

  • NVDA+J opens "Add Placemarker": the Name already contains the text of the line, selected; Valid for chooses "Only this page" or "The whole site" (every page of the site where that text is). The window remembers the last choice. If the line has a link, a button, a heading, a field, a check box, a radio button, a graphic or a tab, the Only if it is check box also appears, followed by the kind of element as NVDA says it (checked by default): this way J moves only to an element of that kind with the same text, and skips paragraphs with the same words. Unchecked, the placemarker is valid for any line with that text. If the line already has a placemarker, NVDA says so and the window does not open.
  • Selected text: if you select a word or a phrase before pressing NVDA+J (for example with Shift+arrows), the placemarker remembers only that and not the whole line. It is useful when the line also has things that change, like "LISTEN· 3:49", where the length is different for every article: you select only "LISTEN".
  • Use for: "Moving there with J" (the default) is the usual placemarker. "Reading it with NVDA+Control+J" makes a placemarker to read: NVDA+Control+J reads the lines of all the placemarkers to read of the page without moving the cursor, useful to check things that change, like a counter or a status message. These placemarkers also have the Announce when it changes check box (Alt+A): when checked, the add-on checks the line again every 2 seconds while you are on the page and, when the text changes, NVDA reads it by itself, without pressing anything. "Clicking it with NVDA+Control+Shift+J" makes a placemarker to click: NVDA+Control+Shift+J clicks all the placemarkers to click of the page, like Enter on each of them, without moving the cursor, for example the Play button of a site; NVDA says "Clicked" with the name, or how many were clicked. "Skipping it with the arrows" makes a placemarker to skip: Up and Down arrow and Control+Up and Down arrow pass over its line as if it were blank, without removing it from the page; it is useful for repeated things that disturb reading, like dates, times or labels. It uses the same check box and the same switch as blank lines: NVDA+Shift+7 turns both blank lines and lines to skip off and on at any time. J and Shift+J only go to "Moving there with J" placemarkers. If the page has none, NVDA says "No placemarkers to read" or "No placemarkers to click".
  • Text to find: the text the placemarker looks for in the page, already filled with the line or the selected text. It can be corrected, for example to remove the part that changes.
  • Where: "Only here" makes the placemarker one point of the page, as in JAWS. "Every time the text appears" makes it valid on every line that contains the text: for example, with "Listen" on the whole site, J goes to every Listen button of every page. The text is searched as whole words ("Listen" does not match inside "Listening") and regardless of upper and lower case. With selected text the proposed choice is "Every time the text appears", otherwise "Only here".
  • Then move by paragraphs (0 by default, from -20 to 20, set with the arrows): after finding the text, J moves the cursor that number of paragraphs forward, or backward if the number is negative; empty paragraphs do not count. It is useful when the point you want to reach has no fixed text but a nearby paragraph does: for example in a forum, above every post there is "Upvote"; with a placemarker on "Upvote" and a move of 1, J goes to the start of the post.
  • Control+Windows+J sets the temporary placemarker, like Control+Windows+K in JAWS: no window, only one per page (pressed again it moves to the line where you are), not saved to a file: it lasts until NVDA restarts. NVDA says "Temporary placemarker set".
  • J and Shift+J move to the next and previous placemarker and read the line. After the last one the cursor stays where it is and NVDA says "No next placemarker" (with Shift+J, before the first one: "No previous placemarker"), as with headings.
  • NVDA+Shift+J opens "Placemarkers": the list of the placemarkers of the page and of the site, with Move to (or Enter), Edit, Delete (or the Delete key), Delete all (asks for confirmation) and Close. Site placemarkers have "(site)" after the name, the temporary one "(temporary)"; those whose text is not on the page are marked "not on this page". A placemarker valid every time appears once for every line, with its number, for example "Listen (site), 2 of 5"; deleting one deletes the placemarker, so all its lines. Edit opens the "Edit Placemarker" window, the same as Add Placemarker and already filled in: you can change name, text to find, Use for, Where, move by paragraphs and Only if it is. "Valid for" cannot be changed: to move a placemarker from one page to the whole site, or the other way round, delete it and make it again.

Pages change: for each placemarker the text of the line and its position are remembered. The text is searched, even if it moved; if it appears more than once, the one with the same lines before and after is chosen, then the one closest to the previous position. If the text is gone, a page placemarker uses the previous position.

In the settings: check box Placemarkers and buttons Manage placemarkers and Delete all the placemarkers.

Manage placemarkers

The Manage placemarkers button, in the Web Navigation settings, opens a window with all the saved placemarkers:

  • Sites and pages (Alt+S): each site or page that has placemarkers, with how many, for example "youtube.com, site: 3".
  • Placemarkers (Alt+P): the ones of the chosen site or page; those valid every time the text appears have "(every time)" after the name.
  • Edit (as in the Placemarkers window), Delete (also with the Delete key) and Delete all of this site or page (asks for confirmation) buttons.
  • Export: saves all the placemarkers to a file, for example to keep a copy or move them to another computer.
  • Import: reads an exported file and asks whether to add the placemarkers to the current ones (those already there are not duplicated) or to replace them all.

The temporary placemarker is not there: it lasts only until NVDA restarts.

Paragraphs at the same level

In discussions with several levels, like the comments of Reddit or of a forum, the replies are indented compared to the message they answer. è goes to the next paragraph that starts at the same distance from the left edge, that is at the same level, skipping the replies; Shift+è goes to the previous one. They are NVDA's "vertically aligned paragraph" commands, which have no key: they exist from NVDA 2024.2, before that the key stays with NVDA. NVDA+è goes one level up: the previous paragraph that starts more to the left, for example the comment being answered; if there is none, NVDA says "No level up". They work in browse mode and are turned off with the quick navigation keys check box. The è key exists only on the Italian keyboard: with other keyboards, assign other keys in Input gestures.

Site settings

NVDA+Control+Shift+S opens the settings of the site of the page, for example "Settings of reddit.com", with two check boxes valid for every page of that site:

  • Silence the automatic announcements of this site (Alt+S): NVDA does not read the notifications and updates that the site announces by itself (the "live regions"), for sites that talk all the time. They can still be read moving with the arrows.
  • Do not switch to focus mode automatically (Alt+F): NVDA stays in browse mode also when the focus goes to a field or another control, for sites that move the focus at the wrong time. To type in a field, switch to focus mode with Enter or NVDA+Space; Escape goes back to browse mode as always.

The site settings are saved in the navigazioneWeb-siti.json file, in the NVDA settings folder.

Go back to where you were

After a jump with H, N, U and the other keys it is often slow to get back to where you were. NVDA+Shift+Left arrow takes the cursor back to where it was before the last jump and reads the line, like the browser's Back key but inside the page. Pressed again, it goes further back. NVDA+Shift+Right arrow does the jump again, like Forward.

  • These count as jumps: NVDA's letters (H, K, N, U and the others) and the add-on's (à, ò, ù, Y), J and Shift+J, Move to in Page elements, the search (NVDA+Control+F, NVDA+F3), Control+Home and Control+End. The arrows and Tab do not count.
  • Up to 20 positions are remembered for each page. A new page starts from scratch. A new jump after going back clears the way forward, as in the browser.
  • If there is nowhere to go, NVDA says "No previous position" or "No next position".
  • It also works in Thunderbird messages.
  • Positions are points in the text of the page: if the page changes a lot while you read it (chats, comments loaded while scrolling), going back may land a few lines away.

The keys work only with the desktop keyboard layout: in the laptop layout NVDA+Shift+Left and Right arrow belong to NVDA (previous and next object) and stay that way. With the laptop layout you can assign other keys in Input gestures. Check box: Go back to where you were with NVDA+Shift+Left arrow.

Smart points

Like the Smart Glance of JAWS. A smart point is a piece of text that stands out to the eye because it has a style that is rare in the page: a color, a background, a font, a size, bold, italic, highlighted text. Often it is not a heading, so H does not reach it: for example a phone number in evidence or a colored notice.

  • Y and Shift+Y: next and previous smart point; NVDA reads its text.
  • NVDA+Control+Y: list of smart points, in the Page elements window (where they are also among the NVDA+F6 types).
  • When the page opens NVDA says how many smart points there are, for example "4 smart points". If there are none it says nothing.

How they are chosen: the most used style is the normal text of the page; smart points are the pieces of text with a style used in a small part of the page, the rarest first. As in JAWS, links, headings and form fields are left out (of the fields, the required ones or those with errors are kept). The calculation is done when needed and done again only if the page changes.

In the settings: Smart points, Announce the smart points when the page opens, Smart points: include links, include headings, include form fields (these three off by default) and Smart points sensitivity: Normal (text with a style used in up to 5% of the page, at most 20 points) or High (up to 15%, at most 50 points).

Where the data is saved

In the NVDA settings folder (usually %APPDATA%\nvda):

  • navigazioneWeb-ricerche.json: the searched words for each page.
  • navigazioneWeb-segnaposti.json: the placemarkers.
  • The settings are in nvda.ini, navigazioneWeb section.

When the add-on is removed these files stay; they can be deleted by hand.

Updates

Every time NVDA starts, the add-on checks on andreadessolis.com whether there is a new version. If there is, it shows what's new and asks whether to update: answering Yes downloads it, checks that the file is the right one and hands it to NVDA, which asks for confirmation, installs it and offers to restart. The check only reads a small file on the site and sends no data.

  • NVDA Settings, Web Navigation category: check box Check for updates when NVDA starts (on by default).
  • The "Checks for updates of this add-on" command, with no key (assign one in Input gestures), checks right away and also tells you when the installed version is already the latest.

Languages

The add-on speaks the language of NVDA: English or Italian.

Compatibility

  • Tested with NVDA 2026.3 (64 bit).
  • Minimum version: NVDA 2024.1, including the 32 bit versions from 2024.1 to 2025.3. The add-on is written only in Python, with no compiled parts, so it does not depend on 32 or 64 bit. This was checked by comparing the NVDA code of those versions, not by trying them.
  • Valid for all NVDA 2026 versions. With NVDA 2027.1, NVDA will mark it as incompatible until a tested version is released.

Known limits

  • Tabs (à): available in NVDA from 2024.1.
  • Focus on the link of headings: on some sites, when a link gets the focus, a menu or a tooltip opens. If it bothers you, turn off the Move the focus to the link of the heading check box.
  • The add-on always takes the first link inside the heading.
  • Smart points: they depend on how the site builds the page. If it uses only one style there are none; if it uses very many there can be too many: in that case try the Normal sensitivity. On very large pages the calculation when the page opens can take a moment.
  • Some features use internal parts of NVDA. After an NVDA update it is worth trying them again.

If something does not work

  • After installing a new version, restart NVDA: the new add-on starts working only after the restart.
  • Check that the feature is on in the settings and that you are not in focus mode.
