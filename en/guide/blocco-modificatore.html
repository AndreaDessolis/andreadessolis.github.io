NVDA Modifier Lock

An NVDA add-on that works like the locked JAWS key: instead of holding down the NVDA key (Insert or Caps Lock) while pressing another key, you can tap it, let it go, and then press the other key.

How it works

  • One tap of the NVDA key (pressed and released on its own): the key stays "pressed". You hear a high beep.
  • The next key is combined with NVDA, then the lock ends by itself. For example: tap Insert, then T, is the same as NVDA+T.
  • Shift, Control, Alt and Windows do not end the lock, so you can use combinations like NVDA+Shift+J: tap Insert, then Shift+J.
  • Another tap of the NVDA key while it is locked unlocks it without doing anything. You hear a low beep.
  • Two quick taps of the NVDA key do its normal function, as in NVDA without the add-on: for example, if Caps Lock is your NVDA key, they turn Caps Lock on or off.
  • Holding the NVDA key down together with another key works as always.
  • Switching to another window removes the lock by itself.

If Windows Sticky Keys are on, the NVDA key is already sticky thanks to NVDA itself, and the add-on does nothing.

Settings

NVDA Settings, NVDA Modifier Lock category:

  • Enable the NVDA modifier lock: turns the feature on or off right away.
  • Turn on automatically when NVDA starts.
  • Feedback when locking and unlocking: Off, Beeps, Speech only, Beeps and speech.

The command "Turns the automatic lock of the NVDA key on or off" (NVDA+Control+Shift+L, can be changed in Input gestures) turns the feature on and off at any time.

Updates

Every time NVDA starts, the add-on checks on andreadessolis.com whether there is a new version. If there is, it shows what's new and asks whether to update: answering Yes downloads it, checks that the file is the right one and hands it to NVDA, which asks for confirmation, installs it and offers to restart. The check only reads a small file on the site and sends no data.

  • NVDA Settings, NVDA Modifier Lock category: check box Check for updates when NVDA starts (on by default).
  • The "Checks for updates of this add-on" command, with no key (assign one in Input gestures), checks right away and also tells you when the installed version is already the latest.

Languages

The add-on speaks the language of NVDA: English or Italian.

Compatibility

NVDA 2023.1 and later. Tested with NVDA 2026.3. With NVDA 2025.1 and later it uses NVDA's official keyboard hook.
