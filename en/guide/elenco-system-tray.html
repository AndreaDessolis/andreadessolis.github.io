System Tray Icons

An NVDA add-on that lists the icons of the Windows notification area (the system tray, next to the clock), hidden ones too, to click them, double click them or open their menu without looking for them with the mouse.

Opening the list

NVDA+F11 opens the "System Tray Icons" window with the list of the icons (the key can be changed in Input gestures, System Tray Icons category). Escape or the Close button close it and the focus goes back where you were.

The list has first the "Show hidden icons" button, then the icons of the programs on the taskbar, then the Windows ones: network, volume, battery, language, clock, Show desktop. The names are on one line, for example "Network Home, Internet access".

Some programs, for example pCloud Drive, put their icon without any name. In that case the add-on looks for the program in the list of icons Windows keeps in the registry: if it finds only one running program with an icon without text, which does not already have an icon with its name, the icon gets the name of the program, for example "pCloud". If there are several possible programs it says all of them, for example "Icon without name: pCloud, Other program"; if it finds none it says "Icon without name". The state of the program (for example whether it is syncing) cannot be known: the program does not say it.

The hidden icons

By default the add-on opens nothing by itself: Enter on "Show hidden icons" clicks that button, the Windows panel with the hidden icons opens and the focus goes there. In the panel you move with the arrows; Enter, the Applications key and Escape are handled by Windows, as with the mouse.

If you prefer to have the hidden icons in the list too, turn on the Include the hidden icons check box in NVDA Settings, System Tray Icons category. Then the "Show hidden icons" button does not appear: to read the hidden icons the add-on opens the panel for a moment and closes it (NVDA stays silent meanwhile), and puts them in the list after the icons of the programs on the taskbar; clicking one of them, the add-on opens the panel again and clicks there. If Windows does not show the "Show hidden icons" button (for example when there are no hidden icons), the add-on notices by itself: it tries the button, and if it does not open the panel it closes it again at once.

The next time, the list opens on the last icon you used.

The commands

KeyWhat it does
Up and Down arrow, or the first letterPrevious icon, next icon or the one starting with that letter
Enter, or the Left click button (Alt+L)The normal click, as with the left mouse button
The Applications key or Shift+F10, or the Right click button (Alt+R)The right click: it opens the menu of the icon
The Double click button (Alt+D)The double click, which in many programs opens the main window

The window closes before the click, so the icon gets it as if you clicked it yourself. Right click and double click use the mouse, which moves onto the icon.

What happens after the click is decided by the program of the icon, as with the real mouse: some programs, to open their menu, also bring their window to the front.

Before the click the add-on reads the icons again and finds the chosen one: if it has disappeared meanwhile, NVDA says "The icon is no longer there".

Settings

NVDA Settings, System Tray Icons category:

  • Include the hidden icons: off by default (see "The hidden icons").
  • Check for updates when NVDA starts.

Why a new add-on

Windows often changes the taskbar: in recent versions of Windows 11 the icons of the notification area are together with Start and the open programs. This add-on does not look for them in a fixed place but in the whole taskbar, so a Windows change breaks it less easily.

Updates

Every time NVDA starts, the add-on checks on andreadessolis.com whether there is a new version and offers to install it. The "Checks for updates of this add-on" command (no key, in Input gestures) checks right away.

Languages

The add-on speaks the language of NVDA: English or Italian.

Compatibility

NVDA 2024.2 and later. Windows 11 (tested with build 26300); on Windows 10 it should list the icons, but it has not been tested. If icons are missing from the list, especially the hidden ones, please report it in the Telegram group: it helps fix it for everyone.
