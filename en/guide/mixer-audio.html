Audio Mixer

An NVDA add-on that puts the Windows audio mixer in one simple window: main volume, microphone and every program with open audio, adjusted with plus and minus.

Opening the mixer

NVDA+Alt+A opens the "Audio Mixer" window (the key can be changed in Input gestures, Audio Mixer category). Escape or the Close button close it and the focus goes back where you were.

The Volumes list

Each row is a channel: Main volume (the default Windows output device), Microphone (the default input device), then every program with open audio, in alphabetical order, and last the System sounds. For example "Chrome: 80%" or "WhatsApp: muted".

It works like a normal list, plus the volume keys:

KeyWhat it does
Up and Down arrowPrevious and next channel
Home and EndFirst and last channel
Plus and minus (also on the numeric keypad)Volume up and down by 5; NVDA says the new value
Asterisk and underscore, or Shift with plus and minus of the numeric keypadVolume up and down by 1 (on the Italian keyboard asterisk and underscore are Shift+plus and Shift+minus)
Page up and Page downVolume up and down by 10
The digits 1 to 9Set the volume to 10, 20 ... 90%; 0 to 100%
SpaceMutes or unmutes the channel
A letterMoves to the channel starting with that letter

Plus and minus of the numeric keypad work with Num Lock on: when it is off, those keys are NVDA commands.

Raising the volume of a muted channel also unmutes it, as in the Windows mixer.

A program that is playing sound right now has "playing" next to its volume, for example "Chrome: 80%, playing": this way you find at once the tab or program that is making sound. The word stays for 3 seconds after the last sound, so it does not disappear at every pause.

The NVDA channel is the voice volume: the same one changed with NVDA's commands or in NVDA Settings, Speech category, and changing it in the mixer changes it there too. NVDA's voice cannot be muted from the mixer (Space says "Not available"). The volume Windows gives to NVDA as a program is not shown: it stays at 100%, so it cannot be lowered by mistake.

The list updates by itself, staying on the chosen channel: the volumes every second, the programs that open or close their audio within 3 seconds (right away when you enter the list). This way the open mixer does not keep the computer busy. A program with several processes or devices (for example Chrome) is a single channel: the volume applies to the whole program.

The channel menu (Enter)

In the Volumes list, Enter opens a menu for the chosen channel:

  • On a program: the Speaker and Microphone submenus, with "Windows default" and all the devices (the one in use is checked); the Reset to Windows defaults item brings the program back to the default devices. If a program plays on a speaker other than the default, its row says so, for example "Chrome: 80%, on Speakers (Senary Audio)". Windows remembers the choice even after a restart. Some programs use it from the next time they start their audio (for example from the next video).
  • On Main volume or Microphone: the list of speakers or microphones, to choose the Windows default. On Main volume there is also the Lock the default speaker item: when checked, if Windows makes another speaker the default (for example when you connect headphones, a USB card or a Bluetooth device) the add-on puts yours back within 2 seconds and NVDA says "Default speaker put back". It works with the mixer closed too. If your speaker is disconnected, it does nothing until it comes back. If you choose another default from the mixer, the lock moves to it. The rows of Main volume and of the locked speaker say "locked".
  • On NVDA: the list of speakers, to choose the one NVDA speaks on (as in NVDA Settings, Audio category). The voice restarts for a moment and then says the speaker name. If NVDA does not use the default, its row says so. There is also the Protect the NVDA volume item: when checked, the volume Windows gives to NVDA as a program stays at 100% and unmuted (if a program or Windows lowers it, the add-on puts it back within 2 seconds, with the mixer closed too), and the add-on asks Windows not to lower NVDA during calls. The NVDA row says "protected".
  • On System sounds there is no menu: NVDA says "Not available".

Choosing the device for each program uses the same Windows feature as the "Volume mixer" in Windows Settings: it exists from Windows 10 version 1803.

The Speakers and Microphones lists

With Tab, after the Volumes list, there are the Speakers list (all the active output devices: speakers, headphones...) and the Microphones list (all the active input devices). In each one the default comes first, with "default" next to it; the others follow in alphabetical order. For example "Headphones (USB Audio): 70%, default".

The keys are the same as in the Volumes list (arrows, plus and minus, digits, Space, Home, End, letters), plus:

  • Enter: makes the device the Windows default, for every use (calls too). NVDA says "Default". Main volume and Microphone, in the Volumes list, follow the new default right away.

The list also updates by itself when a device is plugged in or unplugged.

Windows sounds

In the mixer window, Alt+W (the Windows sounds button) opens a window like the Sounds tab of the Control Panel:

  • Sound scheme (Alt+H): all the schemes, "Windows Default", "No Sounds" and yours. Choose with the arrows; the list of events shows its sounds right away.
  • Events (Alt+E): a tree like the one of the Control Panel, already all open. The branches are the programs ("Windows", "File Explorer", "Windows Speech Recognition"...), under them their events with the sound, for example "Critical Stop: Windows Critical Stop" or "Complete Navigation: no sound". With the first letter you go straight to the event; left and right arrow close and open a branch, Enter on a branch opens or closes it. Space plays the sound; Delete removes it (no sound); Enter opens a menu with Listen, Choose a file… (a .wav file), No sound and Back to the sound of the scheme.
  • Save scheme as… (Alt+V): saves the sounds of the list right away as a new scheme, with the name you write; it becomes the chosen scheme. Delete scheme (Alt+D): deletes the chosen scheme, after a question; Windows schemes cannot be deleted.
  • During calls (Alt+C), like the Communications tab: what Windows does to the other sounds when you are in a call. It mutes all other sounds, reduces them by 80% or 50%, or does nothing.
  • Play the Windows startup sound (Alt+S). This setting can only be changed as administrator: pressing OK, the Windows User Account Control request appears; after confirming NVDA says "Startup sound on" or "off", if you refuse it says "Startup sound not changed".

OK applies the scheme, the changed sounds and the other choices; Cancel (or Escape) leaves everything as it was, except the schemes already saved or deleted, as in the Control Panel. The focus goes back in the mixer where you were.

Updates

Every time NVDA starts, the add-on checks on andreadessolis.com whether there is a new version and offers to install it. NVDA Settings, Audio Mixer category: check box Check for updates when NVDA starts. The "Checks for updates of this add-on" command (no key, in Input gestures) checks right away.

Languages

The add-on speaks the language of NVDA: English or Italian.

Compatibility

NVDA 2024.2 and later, Windows 10 and 11. Tested with NVDA 2026.3.
