Window Manager

An NVDA add-on that lists all the windows open in Windows, to bring them to the foreground or close them. It also finds secondary windows and dialogs (for example the render window or the track manager of REAPER).

Usage

  • NVDA+W opens the "Open Windows Manager" window. The key can be changed in Input gestures, Window Manager category.
  • The windows are in Alt+Tab order: the first one is the window you were using. The program name is added after the title, unless the title already says it (for example "Telegram" or "Document - Microsoft Word" stay as they are).
  • Enter (or the Activate button): brings the window to the foreground, restoring it if it is minimized.
  • Delete (or the Close window button): asks the program to close the window, like clicking its X. The list is updated and stays on the same row.
  • Escape (or Cancel): closes the list.

When a window does not close or does not activate

  • If the program asks something before closing (for example "Do you want to save the changes?"), NVDA says "The program asks for confirmation" and brings that question to the front, so you can answer it.
  • If the window does not close and asks nothing, NVDA says "The window did not close".
  • If Windows does not allow the window to come to the foreground (this happens for example with programs run as administrator), NVDA says "Cannot bring the window to the foreground".

Languages

The add-on speaks the language of NVDA: English or Italian.

Compatibility

NVDA 2023.1 and later. Tested with NVDA 2026.3.
