What's new in Window Manager

Versions from the most recent. What's new in the installed version can also be read in the NVDA add-on manager.

Back to Window Manager

Version 1.2.1

New

  1. Automatic updates: every time NVDA starts, the add-on checks for a new version, shows what's new and offers to install it. They can be turned off in NVDA Settings, Window Manager category, and checked by hand with the "Checks for updates of this add-on" command in Input gestures.

Fixes

  1. Enter brings the chosen window to the foreground again: since version 1.1 NVDA often said "Cannot bring the window to the foreground".

Version 1.2.0

New

  1. The add-on speaks the language of NVDA: English or Italian.
  2. Guide in English and Italian.
  3. Package made like the official NVDA add-ons: translated name, description and changes, license.
  4. In Input gestures the category is called Window Manager, like the add-on.

Version 1.1

New

  1. The program name is shown next to the window title, unless the title already says it.
  2. If the program asks for confirmation before closing (for example whether to save), the question is brought to the front.
  3. NVDA says when a window did not close or cannot be brought to the foreground.
  4. Enter and Delete act only once; the window opens and closes like NVDA's own dialogs.
  5. No more messages in the NVDA log at every use.
  6. The guide opens from NVDA's add-on manager.
