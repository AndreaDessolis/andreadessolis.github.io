What's new in Shortcut Conflict Helper

Versions from the most recent. What's new in the installed version can also be read in the NVDA add-on manager.

Back to Shortcut Conflict Helper

Version 1.3.1

New

  1. Automatic updates: every time NVDA starts, the add-on checks for a new version, shows what's new and offers to install it. They can be turned off in NVDA Settings, Key Conflicts category, and checked by hand with the "Checks for updates of this add-on" command in Input gestures.

Version 1.3.0

New

  1. The add-on speaks the language of NVDA: English or Italian.
  2. Guide in English and Italian.
  3. Package made like the official NVDA add-ons: translated name, description and changes, license.

Fixes

  1. When the last conflict is ignored with no other changes, it no longer asks to press OK: Ignore is saved by itself.

Version 1.2.0

New

  1. Search by key button in Input gestures: press a key and the tree shows only the commands that use it.

Version 1.1.0

New

  1. The conflicts window opens only when there are conflicts, on top of Input gestures.
  2. Tells which command wins for each key, following NVDA's order.
  3. Edit, Remove and Ignore buttons; ignored conflicts come back if another command is added to the same key.
  4. Warns before assigning a key that is already used.
  5. Settings in the Key Conflicts category.
