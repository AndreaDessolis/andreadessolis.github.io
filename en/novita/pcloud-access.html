What's new in PCloud Access

Versions from the most recent. The same notes are in the program, in Help.

Back to PCloud Access

Version 1.1.0, October 23, 2026

New

  1. Two-factor authentication: you can now sign in also with accounts that ask for a code by SMS, in the pCloud app or with an authenticator app. After email and password the code field appears with the "Send me the code by SMS" and "Send it to the pCloud app" buttons; if you get the code by SMS, it is sent by itself. Backup codes work too, with the "This is a backup code" box.

Fixes

  1. Sign-in now works like on the pCloud website: the program first asks pCloud how to sign in with that email, and the email code is requested only when pCloud wants it. Before, with some accounts, the error "Two factor authentication required" appeared, or the program said it had sent the code by email but the code never arrived.
  2. If pCloud ever replies in an unexpected way, the program shows an error instead of closing.

Version 1.0.1, October 20, 2026

Fixes

  1. Create an account gave the error "Invalid request (code 1101)": pCloud no longer lets other programs create an account. Now the "Create an account on the pCloud website..." button explains what to do and opens the pCloud sign-up page in your browser; once the account is ready, you come back to PCloud Access and sign in with email and password.

Version 1.0.0, October 20, 2026

New

  1. First official version of PCloud Access: your pCloud like a Windows folder, designed for NVDA and JAWS users.
  2. File list like in File Explorer: View menu (Layout, Sort by, Group by), Properties, copy, cut and paste also with File Explorer, rename, trash, previous versions and Undo (Ctrl+Z).
  3. Tabs (Ctrl+T, Ctrl+Tab, Ctrl+W), Back and Forward (Alt+arrows), Favorites (Ctrl+B to add, Ctrl+Shift+Down arrow to open them) and Recent items (Ctrl+Shift+Up arrow).
  4. Uploads and downloads with the Transfers window (Ctrl+Shift+T): numbers first and then the name, with the Speed and Transferred boxes; spoken status even from other programs (Ctrl+Shift+Alt+T), pause and progress announcements.
  5. Enter opens any file: audio and video play without downloading, in the quality you choose; other files open with their program and, if you save them, go back to pCloud by themselves.
  6. Public links, links to receive files, shared folders and invitations, pCloud Transfer, zip, collections, search, other people's links and downloading from the internet straight into pCloud.
  7. Your account: sign-in with email verification, connected devices, password, email, email language, newsletter, inviting friends.
  8. Automatic updates signed by the author: the program checks by itself whether there is a new version and installs it when you say yes.

Good to know

  1. The full guide (in Italian) opens with F1 from any window. Settings are in Tools, Settings (Ctrl+Comma): spoken announcements and sounds, shortcuts, listening quality, tabs, recent items and hidden system files.
