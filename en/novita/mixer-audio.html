What's new in Audio Mixer

Versions from the most recent. What's new in the installed version can also be read in the NVDA add-on manager.

Back to Audio Mixer

Version 1.0.0

New

  1. First complete version, published on the site: from now on the add-on updates itself when NVDA starts.
  2. NVDA+Alt+A opens the mixer: volumes of main volume, microphone, NVDA and every program, with plus and minus, digits and Space; Speakers and Microphones lists to choose the defaults; device for each program; "playing" next to who is making sound.
  3. Lock of the default speaker and protection of the NVDA volume, with the mixer closed too.
  4. Windows sounds (Alt+W in the mixer): sound scheme, tree of events with listening and choice of files, save and delete scheme, what Windows does during calls and startup sound.

Version 0.5.0

New

  1. Windows sounds: in the mixer window the Windows sounds button (Alt+W) opens a window like the Sounds tab of the Control Panel, with the sound scheme (also the ones you created), what Windows does to the other sounds during calls and the Windows startup sound. For the startup sound Windows asks for administrator permission.
  2. In the same window, the tree of events as in the Control Panel (the programs, and under them their events, all open: the first letter goes to the event) with their sound: Space plays it, Delete removes it, Enter opens the menu to choose a .wav file, remove the sound or go back to the one of the scheme. The Save scheme as and Delete scheme buttons.

Version 0.4.0

New

  1. The lists work like normal lists: up and down arrow choose the channel, plus and minus (also on the numeric keypad) raise and lower the volume by 5, asterisk and underscore by 1, Page up and down by 10, the digits 1 to 9 set the volume to 10-90% and 0 to 100%.
  2. Who is playing: a program that is making sound has "playing" next to its volume, for example "Chrome: 80%, playing".
  3. Lock of the default speaker (Enter on Main volume): if Windows makes another speaker the default, for example when connecting headphones or a Bluetooth device, the add-on puts yours back. It works with the mixer closed too.
  4. Protection of the NVDA volume (Enter on NVDA): the volume Windows gives to NVDA stays at 100%, and the add-on asks Windows not to lower NVDA during calls. It works with the mixer closed too.

Fixes

  1. With the mixer open the computer no longer works so hard (fast fans): before, every second all the devices and program names were read again, opening the program files. Now the names are read only once, every second only the volumes are read again and the list you are in is read again completely every 3 seconds.

Version 0.3.1

New

  1. Enter on the NVDA channel opens the list of speakers to choose NVDA's one, as in NVDA Settings, Audio category. The NVDA row says which speaker it speaks on, if it is not the default.

Version 0.3.0

New

  1. Enter on a program, in the Volumes list, opens a menu to choose its speaker and its microphone, or to go back to the Windows defaults. The row says which speaker the program plays on, if it is not the default.
  2. Enter on Main volume or Microphone opens the list of devices to choose the Windows default.

Version 0.2.1

New

  1. Speakers and microphones are in two separate lists.

Fixes

  1. Enter really makes the device the default: before, the window intercepted it.
  2. Closing the mixer no longer makes NVDA restart: the automatic list update stops before closing.

Version 0.2.0

New

  1. Devices list: all the active speakers and microphones, with volume and mute as in the Volumes list; Enter makes the device the Windows default, for every use.

Version 0.1.2

New

  1. The NVDA channel adjusts the voice volume, the same as NVDA's commands and settings. The volume Windows gives to NVDA stays at 100% and is not shown, so it cannot be lowered by mistake.

Version 0.1.1

Fixes

  1. The arrow keys no longer read everything twice: the channel change is read only by NVDA, and adjusting the volume says only the new value.

Version 0.1.0

New

  1. First test version: NVDA+Alt+A opens the mixer with the Volumes list (main volume, microphone and every program), adjusted with the arrow keys like the faders of a mixer.
