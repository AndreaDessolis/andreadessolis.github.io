What's new in Web Navigation

Versions from the most recent. What's new in the installed version can also be read in the NVDA add-on manager.

Back to Web Navigation

Version 1.5.0

New

  1. Placemarkers from the selected text: if you select a word or a phrase before NVDA+J, the placemarker remembers only that and not the whole line. Useful when the line also has things that change, like "LISTEN· 3:49" where the length changes for every article. Thanks to Amir for the suggestion.
  2. Placemarkers valid every time the text appears: in the Add Placemarker window, the "Where" list chooses between "Only here" (one point of the page, as before) and "Every time the text appears": J goes to every line with that text, for example to every Listen button of a site. The text is searched as whole words and regardless of upper and lower case. In the Placemarkers window (NVDA+Shift+J) every line appears with its number, for example "Listen (site), 2 of 5". Thanks to Amir for the suggestion.
  3. Move after the found text: in the Add Placemarker window, "Then move by paragraphs" (0 by default, from -20 to 20) takes the cursor some paragraphs after or before the found text, not counting empty paragraphs. For example, with a placemarker on "Upvote" and a move of 1, J goes to the start of the post that follows. Thanks to Amir for the suggestion.
  4. Placemarkers to read, to click and to skip: in the Add Placemarker window, the "Use for" list chooses between "Moving there with J" (as before), "Reading it with NVDA+Control+J", "Clicking it with NVDA+Control+Shift+J" and "Skipping it with the arrows". The lines of the placemarkers to skip are skipped by Up and Down arrow like blank lines (for dates, times, repeated labels), and NVDA+Shift+7 turns them off and on at any time too. NVDA+Control+J reads all the placemarkers to read of the page without moving the cursor (for example a counter or a status message); NVDA+Control+Shift+J clicks all the ones to click (for example the Play button), also without moving the cursor. For placemarkers to read, the "Announce when it changes" check box makes NVDA read the line by itself as soon as its text changes (the add-on checks it every 2 seconds). Thanks to Amir for the suggestion.
  5. Saved placemarkers can be edited: in the Placemarkers window (NVDA+Shift+J) and in Manage Placemarkers the Edit button (instead of Rename) opens the placemarker window already filled in, to change name, text to find, Use for, Where, move by paragraphs and Only if it is. The Add Placemarker window also has the Text to find field, to correct the text before saving it.
  6. Paragraphs at the same level, for discussions with several levels like the comments of Reddit: è and Shift+è go to the next and previous paragraph that starts at the same distance from the left edge, skipping the replies (they are NVDA's "vertically aligned paragraph" commands, which have no key: from NVDA 2024.2); NVDA+è goes one level up, for example to the comment being answered. The è key exists only on the Italian keyboard: with other keyboards, assign other keys in Input gestures.
  7. Site settings: NVDA+Control+Shift+S opens a window with two check boxes valid for every page of the site: "Silence the automatic announcements of this site", for sites that talk all the time, and "Do not switch to focus mode automatically", for sites that move the focus at the wrong time.

Version 1.4.1

Fixes

  1. Enter switches to focus mode also when the cursor is on the text that a site draws inside an empty field, for example the invitation to type in the ChatGPT message field: before, NVDA only clicked it, because that text is not the field. On links, buttons and the other elements Enter does what it does in NVDA. It can be turned off in the settings, "Enter on the text drawn inside a field switches to focus mode" check box.

Version 1.4.0

New

  1. Go back to where you were: NVDA+Shift+Left arrow takes the cursor back to where it was before the last jump (H, N, U and the other letters, J, Page elements, the search, Control+Home and Control+End) and reads the line; pressed again it goes further back, up to 20 positions for each page. NVDA+Shift+Right arrow does the jump again. Desktop keyboard layout only (in the laptop layout those keys belong to NVDA). It also works in Thunderbird messages; it can be turned off in the settings. Thanks to Amir for the suggestion.

Version 1.3.2

New

  1. In the Add Placemarker window (NVDA+J), if the line has a link, a button, a heading, a field, a check box, a graphic or a tab, the "Only if it is" check box (checked by default) makes the placemarker valid only for that kind of element: J no longer stops on paragraphs with the same words. Thanks to Amir for the suggestion.

Fixes

  1. Every line on which NVDA would only say "blank" is now skipped, on any site, also when the line is made of hidden elements with no text: for example the about 30 blank lines at the top of GitHub pages. Thanks to Amir for the report.
  2. J and Shift+J no longer start again from the other side without warning: after the last placemarker the cursor stays where it is and NVDA says "No next placemarker" (with Shift+J "No previous placemarker"), as with headings.

Version 1.3.1

Fixes

  1. Blank lines are also skipped in tables: an empty cell no longer stops the Up and Down arrows (for example in the Bookshare book list). NVDA's table commands (Control+Alt+arrows) still stop on empty cells too. Thanks to Amir for the report.

Version 1.3.0

New

  1. NVDA+Shift+7 quickly turns skipping blank lines on and off (on the Italian keyboard Shift+7 is the slash). It can be changed in Input gestures.
  2. In Thunderbird messages, skipping blank lines, Open the link where you are, Page elements (NVDA+F6) and smart points (Y) also work.
  3. In the settings, the Manage placemarkers button opens the list of sites and pages that have placemarkers: they can be viewed, renamed and deleted, also all the ones of a site, and exported to a file and imported from a file. Thanks to Amir for the suggestions.
  4. The searched word is also remembered for the whole site: on a page where you never searched, Control+F proposes the last word searched on that site. In the settings, the "Remember the searched word for" list chooses between Page, then site (default), Page only and Site only.

Fixes

  1. In Thunderbird messages, the letters of web-only commands (for example J for placemarkers) no longer reach Thunderbird: they stay with NVDA, as without the add-on.

Version 1.2.0

New

  1. Blank lines are skipped: in web pages, Up and Down arrow (lines) and Control+Up and Down arrow (paragraphs) no longer stop on empty lines, as in JAWS. Lines with a graphic, a field or another element are always read. It can be turned off in the settings, "Skip blank lines when moving with the arrows" check box. Thanks to Amir for the suggestion.

Version 1.1.1

New

  1. Automatic updates: every time NVDA starts, the add-on checks for a new version, shows what's new and offers to install it. They can be turned off in NVDA Settings, Web Navigation category, and checked by hand with the "Checks for updates of this add-on" command in Input gestures.

Version 1.1.0

New

  1. The add-on speaks the language of NVDA: English or Italian.
  2. Guide in English and Italian.
  3. Package made like the official NVDA add-ons: translated name, description and changes, license.

Fixes

  1. The add-on acts only on web pages: in Outlook, Word, WordPad and other programs its keys do what they do in NVDA.
  2. NVDA+A reports the page address only with the desktop keyboard layout: in the laptop layout it stays NVDA's say all.

Version 1.0.0

New

  1. Links in headings: the full label is read (YouTube video length) and the focus moves to the link.
  2. Open the link where you are with Shift+Enter, Control+Enter, Control+Shift+Enter and the Applications key.
  3. Page address with NVDA+A.
  4. JAWS-like quick navigation keys for tabs, articles and the main landmark, which scroll the page to look for more elements.
  5. A search that remembers the word for each page.
  6. Page elements with NVDA+F6.
  7. Placemarkers, also temporary.
  8. Smart points, like the Smart Glance of JAWS.
