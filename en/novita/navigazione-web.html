What's new in Web Navigation

Versions from the most recent. What's new in the installed version can also be read in the NVDA add-on manager.

Back to Web Navigation

Version 1.1.0

New

  1. The add-on speaks the language of NVDA: English or Italian.
  2. Guide in English and Italian.
  3. Package made like the official NVDA add-ons: translated name, description and changes, license.

Fixes

  1. The add-on acts only on web pages: in Outlook, Word, WordPad and other programs its keys do what they do in NVDA.
  2. NVDA+A reports the page address only with the desktop keyboard layout: in the laptop layout it stays NVDA's say all.

Version 1.0.0

New

  1. Links in headings: the full label is read (YouTube video length) and the focus moves to the link.
  2. Open the link where you are with Shift+Enter, Control+Enter, Control+Shift+Enter and the Applications key.
  3. Page address with NVDA+A.
  4. JAWS-like quick navigation keys for tabs, articles and the main landmark, which scroll the page to look for more elements.
  5. A search that remembers the word for each page.
  6. Page elements with NVDA+F6.
  7. Placemarkers, also temporary.
  8. Smart points, like the Smart Glance of JAWS.
